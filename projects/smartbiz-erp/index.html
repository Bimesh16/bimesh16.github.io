The context

Connect everyday business operations.

SmartBiz ERP brought finance, HR, inventory, and reporting into a shared platform for small and medium businesses across retail, manufacturing, and finance. I contributed APIs, database integration, access controls, and performance improvements within the backend team.

My contributions

From service logic to delivery.

  1. Connect the modules

    Designed Spring MVC REST APIs and Spring/Hibernate services linking accounting, HR, and inventory workflows.

  2. Improve the financial data path

    Optimized the MS SQL Server schema and refactored stored procedures and complex joins to reduce redundant queries and I/O bottlenecks.

  3. Enforce access across workflows

    Integrated Spring Security with LDAP for role-based access and single sign-on across modules.

  4. Validate and release

    Wrote unit and integration tests for API calls, database transactions, and access flows; contributed feature releases supporting more than 30 SMB clients.
